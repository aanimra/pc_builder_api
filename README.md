# PC Components Catalog Web Service

REST API сервіс для управління каталогом комплектуючих персональних комп'ютерів. Забезпечує базові CRUD-операції для товарів, валідацію вхідних даних та автоматичну документацію.

## Використані технології

- **Мова:** Python 3.11
- **Фреймворк:** FastAPI
- **Документація:** OpenAPI, Swagger UI (`/docs`), ReDoc (`/redoc`)
- **Тестування:** Pytest, HTTPX

## Запуск тестів

Щоб запустити модульні тести локально:

```bash
pip install -r requirements.txt
pytest -v
```
